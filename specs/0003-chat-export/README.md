# Codexの会話をMarkdownへ出力

状態: 実装・ローカル確認済み、CI確認中

## 目的・範囲

参照元の `.cursor/skills/export-chat/` と同様に、セッション開始時刻のフォルダへユーザー・アシスタントの本文をMarkdown出力する。Codexの実際のJSONLに合わせ、Python標準ライブラリだけで実装する。

## 決定事項

- `scripts/export_chat.py --transcript <JSONLまたは->` を開発コンテナ内で実行する。標準入力に対応し、ホストのログをコンテナ内へ永続コピーせずに渡せるようにする。
- 出力先は `chat-exports/YYYY-MM-DD-HHMM/chat.md`。時刻は `session_meta` の開始日時を日本時間へ変換する。同じ会話の再出力は上書き、同時刻の別会話は上書きせずエラーとする。
- `response_item` のユーザー・アシスタントのメッセージだけを読み、重複するイベント、ツール、推論、システム・開発者指示、圧縮時の要約を除外する。環境・ブラウザの自動付加情報も除外する。
- 問い合わせへの選択回答は質問・回答として出力する。画像は添付の表示だけを残す。
- 生成物はGit管理対象外。スクリプトと利用手順はコミットし、会話ログ自体は明示依頼がなければコミットしない。
- この会話の実ログで動作確認する。アプリ本体と教材は変更しない。

## 確認観点

本文と順序・改行の保持、機密の内部レコードの除外、イベントとの二重出力防止、日付と時差、再出力、別会話の衝突、不正JSONの診断、入力エラー時の既存出力保持をテストする。

## 確認結果

- 開発コンテナ内で `python3 -m unittest discover -s tests/tools -p 'test_*.py'` が7件成功。
- この会話のJSONLをホストから標準入力で渡し、`chat-exports/2026-10-19-2046/chat.md` を出力。初回依頼・比較条件・今回の依頼の保持と、自動付加情報の除外を確認した。
- `npm run export:chat -- --transcript <ファイル> --repo-root <一時保存先>` も成功し、ファイル入力・npm経由の実行を確認。
- CI内にもPythonの7件を追加。既存のアプリ検証・教材検証・公開処理も維持する。
