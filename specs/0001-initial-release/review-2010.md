# 2010年度の教材レビュー

2026-10-20、2010年度25問の補助テキストと解説を保存し、別工程で原画像・公式正解・必要な一次資料と照合した。結果は `review-2010.csv` に5問ずつ保存した。

- 草稿の構文木から2010年度の25問だけを選んで反映した。2009年度JSONのSHA-256が処理前後で同一であることを確認した。
- `stem` と `choices` は原文の要約又は図表のテキスト表現で、逐語転記ではない。問題全文はIPA原本画像を参照する。
- 保存後に全25問の画像を個別に目視し、解説を読み直した。同じ担当者による別工程のレビューであり、別人による監査ではない。
- 問2の生産性の指数・曲線、問7のEVM差異、問8の残期間を開発コンテナ内で独立に再計算した。
- 問23は2007年モデル契約の原版URLが取得できなかったため、IPA「ユーザのための要件定義ガイド第2版」本文276〜277頁の2007年モデルを引用した説明・図を確認した。要件定義を準委任とする前提で、他の3肢を除外できることを照合した。
- ITILはv3を前提とし、OECD・派遣法の説明は一次資料に照合した。出題後の制度やモデルの内容を出題当時のものとして読み替えていない。
- CSV必須列、25問の番号、公式正解表と解説冒頭の一致、補助文の存在を開発コンテナ内で検証した。

2011年度以降は今回の作業対象に含めていない。
