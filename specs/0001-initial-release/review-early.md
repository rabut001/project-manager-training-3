# 初期年度の教材レビュー記録

2026-10-20、2009年度25問の作成後レビューを実施した。各問の結果は `review-early.csv`。

- 抽出画像の確認とは別工程で、保存済みの補助テキスト・解説を原画像、IPA公式正解表、必要な一次資料と照合した。同じ担当による別工程の再確認であり、別人による監査ではない。
- `stem` と `choices` は原文の要約又は図表のテキスト表現。全文の逐語転記ではない。問題全文は公開するIPA原本画像を参照する。
- 問1・問4の計算は開発コンテナ内で独立に再計算した。問2・問10・問12・問19の図表を目視で再照合した。
- 問24の解説はレビュー時に、未定事項を後で補充する場合の未定理由・確定予定期日・補充書面交付の条件を明確化した。2026年1月の取適法施行は公取委の一次資料で確認した。
- 2009年度全25問の正解と解説冒頭の正解表示をIPA解答表に再照合した。2010年度以降はこのレビューに含めない。

作業草稿 `.cache/author-early.py` には、2009年度分と未反映の2010年度25問がある。年度単位の再開時に対象年度だけを反映すること。全体を実行すると2009年度も再保存するため、無条件に実行しない。
