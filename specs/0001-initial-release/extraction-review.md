# IPA原本・問題画像の抽出確認

確認日: 2026-10-20（日本時間）

## 対象と方法

2009〜2025年度の17回、問題425件を確認した。IPA公開ページにリンクされた問題・正解PDFを取得し、URLとSHA-256を `sources/ipa/manifest.json` に記録した。原本は公開用ディレクトリに含めない。

抽出工程とは別に `scripts/review_images.py` で、原本ページ上の切り出し矩形と、出力した25問の画像一覧を年度ごとに生成して目視した。全年度で、問番号の順序、本文・選択肢・図表が矩形に収まること、別の問が混入しないことを確認した。範囲が不明瞭な2016年問1・2は個別画像と原本部分を拡大して確認・修正した。隣接矩形間の隙間に文字が残らないことも画素検査した。

これは画像の欠落・問題対応の確認であり、OCR全字の校正や解説内容のレビューとは別である。作業用OCRは `.cache/text/YYYY.txt`、目視用一覧は `.cache/image-review/` に生成できる。キャッシュは公開・Git管理しない。再現に必要な原本・座標は `sources/ipa/<試験回>/crops.json` に保存する。

正解は原則、公式正解PDFの埋め込みテキストから問番号に対応付けて取得し、17回の公式正解表の画像一覧と公開データの回答列を別工程で再照合した。2021年は表に抽出可能なテキストがなく、公式表の画像を読んで `answer-overrides.json` に転記した。

## 見つかった例外と修正

- OCRで問10を問19、問20を問29等と誤認する例があった。連番1〜25の検査で止め、原本の見出し画像を目視して `header-overrides.json` に補正座標を保存した。欠けた問を推定で削除・補充しない。
- 2016年度問2は公式正解PDFに「誤りにより問題として成立しない」と明記。問題PDFにも全員正解の措置済みとの注記がある。注記を問2の画像に含め、`answer: null` と `invalidReason` を記録した。学習アプリでは採点対象外とする。通常の正解を割り当てない。
- 当初2016年度問2の注記が問1と問2に分断されていた。注記の上へ境界を移動して全体を問2に収め、個別画像で修正結果を確認した。
- 古い抽出画像の末尾に残った冊子ページ番号と余白を削除し、本文・図表・選択肢を維持した。

## 結果

425画像、424問の通常正解、1問の公式出題不備を収録。問題数と順序、出典ページ、元PDFへの対応を各問のCSVへ記録した。公開可否は別途行う解説レビューを含む完成判定に従う。
