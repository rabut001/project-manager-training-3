# 2011年度特別試験 教材作成・別工程レビュー

初回リリース案件内の年度別作業記録。目的は25問の補助テキストと解説を完成させ、公式正解・問題画像と整合することを確認すること。

## 手順・確認観点

- 原画像とOCRを参照し、5問ずつ補助テキスト・解説を公開JSONに保存する。
- 保存後に内容を読み直し、原画像の条件・選択肢・公式正解との整合性を別工程で確認する。同じ担当による作成後レビューであり、別の担当者による独立レビューではない。
- `stem` / `choices` は検索等の補助用の要約を含む。表示正本はIPA原本から切り出した問題画像であり、逐語転記は目的としない。図形選択肢は原図の参照で表す。
- 問4・20・22は数値を原図から読み、計算を再実行する。問17はデータの入出力方向を目視する。問24・25は出題当時の法令を前提とし、現行注記がある場合は一次資料も確認する。
- 5問ずつ `review-2011.csv` に確認根拠を保存する。完了時に25行・必須列・正解との一致を検証する。

対象は2011年度のみ。他年度の完成データには変更を加えない。
