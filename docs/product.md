# 現在の製品仕様

初回実装・教材完成、公開準備中。ユーザー承認済み方針（2026-10-19）。

## 対象
PM午前Ⅱの2009〜2025年度17回425問。2011年度は特別試験、2020年度は10月試験。2026年度の名称は科目A-2である旨を補足する。IPA公開済み原本だけを使用する。

## 操作
- 年度一覧と1問ずつ解く演習画面。年度は新しい順。
- 画像、ア〜エ選択、結果確認、正誤・正答・自作解説の順。確認前は選び直せる。確認後は固定。
- 一括採点は選択済み・未確認だけが対象。未選択は正解率の分母に含めない。
- 前後移動と1〜25の番号移動。チェックは正誤と独立。
- 解答の一括クリアは当該回だけに適用し、チェックを残す。採点とクリアは確認ダイアログを出す。
- 選択・確認状態・現在問・チェックをlocalStorageに保存する。ログイン・同期なし。
- 保存できない場合も学習操作を継続し、保存されないことを表示する。
- 2016年度問2は公式の出題不備。画像・公式注記・説明は残し、解答選択と採点を行わず正解率の分母にも含めない。当時の試験では全員正解措置だが、この学習アプリでは理解度の計算から除く。チェックと前後移動は使える。

## UI
参照元の生成り背景・青の選択状態・正誤の色と記号を継承。スマートフォンは問題から解説まで自然な縦スクロールとし、回答に必要な操作を下部に固定する。固定部で本文を隠さない。問題画像はタップで拡大。解説は段落で区切る。タッチ・キーボード・読み上げラベルを整備。PCでも本文を過度に広げない。

## 構成
React・TypeScript・Vite・通常のCSS。静的JSONと画像。年度を選んだ時だけ該当データを取得。ハッシュURLを使用し、GitHub Pagesのサブパスに対応。Node.js 24とnpm、Python、PDF/OCRツールは開発コンテナに含める。

## 内容品質
元PDF、URL、取得日、ハッシュ、問題のページ・切り出し位置を保持。原本との照合、正解の照合、解説の別工程レビューを全問実施する。計算は再計算。制度・法令は出題時の前提を確認。出典と非公式解説の表示を行う。解説は事前作成し、実行時生成はしない。
